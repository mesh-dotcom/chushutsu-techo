# 抽出手帖

豆ごとにホット／アイスの抽出レシピを記録し、項目から類似検索できる手帖です。

公開URL: https://mesh-dotcom.github.io/chushutsu-techo/

## データの保存について

- 記録は、お使いのブラウザの localStorage にだけ保存されます。
- 記録をどこかへ送信することはありません（外部への通信は Google Fonts の読み込みのみ）。

## バックアップと引っ越し

- ときどき「JSONで書き出す」でバックアップを取ってください。
- 新しい端末やURLへデータを移すときは、元の場所で「JSONで書き出す」を行い、移行先で「JSONを読み込む」から取り込みます。
